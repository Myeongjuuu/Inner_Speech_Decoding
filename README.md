# ICASSP 2027

Inner-speech EEG research code. This first snapshot preserves the two original code folders before refactoring.

- `EEG Inner Speech Decoding/`: preprocessing, CSP, coherence and multitaper experiments.
- `Imagined Speech Decoding using Functional Connectivity/`: preprocessing and exploratory PLV analysis.

Original code and saved outputs are preserved; recordings, checkpoints and external weights are excluded. `SOURCE_MANIFEST.json` records SHA-256 checksums of the 17 originals. These historical notebooks are not a validated end-to-end pipeline.

Dataset: [OpenNeuro ds003626 v2.1.2](https://doi.org/10.18112/openneuro.ds003626.v2.1.2), [data descriptor](https://doi.org/10.1038/s41597-022-01147-2).
